### Code Sample – JavaScript (Codewars)

**Task:** Convert a string to camelCase  
**Challenge Level:** 6 kyu  
**Description:** Transform a sentence into camelCase format, removing spaces and capitalizing each word except the first.

```javascript
function toCamelCase(str) {
  return str
    .split(/[-_]/)
    .map((word, index) =>
      index === 0 ? word : word[0].toUpperCase() + word.slice(1)
    )
    .join('');
}
```
